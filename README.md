# 🚢 Análise de Dados - Titanic

## 📌 Objetivo
Este projeto tem como objetivo realizar uma análise dos dados do Titanic, buscando identificar padrões relacionados à sobrevivência dos passageiros.

---

## 📊 Tecnologias utilizadas
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

## 📁 Estrutura do projeto
- `script.py`: Código principal da análise
- `data/titanic.csv`: Base de dados utilizada
- `images`: Imagens de algumas tabelas geradas.

---

## 🔍 Análises realizadas

- Distribuição de sobreviventes
- Análise por sexo e classe
- Idade dos passageiros
- Tarifas pagas
- Passageiros sozinhos vs acompanhados

---

## 📈 Visualizações

- Gráfico de barras (countplot)
- Histograma
- Scatterplot
- Boxplot
- Gráfico de linha

---

## 💡 Principais insights

- Mulheres tiveram a maior taxa de sobrevivência
- Passageiros da primeira classe tiveram mais chances de sobreviver
- Idade influencia parcialmente na sobrevivência

---

## ▶️ Como executar

```bash
pip install pandas numpy matplotlib seaborn
python script.py
```
